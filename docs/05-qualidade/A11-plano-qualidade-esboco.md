# A11 — Plano inicial de qualidade — Esboço

> Versão preliminar, preparada em 11/11/2026 como ponto de partida da entrega final. Preservada para registrar a evolução descrita na seção 2.7 de [A11-plano-qualidade.md](A11-plano-qualidade.md). Não representa trabalho realizado em oficina.

## Características pensadas

| Característica | Por que importa | Meta |
|---|---|---|
| Usabilidade | O atendente quer um sistema simples | Sistema fácil de usar |
| Desempenho | O balcão não pode esperar | Telas rápidas |
| Segurança | Valores e dados administrativos | Sistema seguro |
| Confiabilidade | Não perder ordens de serviço | Não perder dados |
| Funcionalidade | Fazer o que foi pedido | Requisitos atendidos |
| Manutenibilidade | Dupla vai evoluir o código | Código organizado |

## Observações do esboço

- Seis características, acima do limite de cinco do enunciado.
- Nomes antigos (ISO/IEC 25010:2011): "Usabilidade" e "Funcionalidade" não são os termos da versão 2023.
- Metas sem número ("rápido", "seguro", "fácil") e sem forma de verificação.
- Justificativas sem códigos do dossiê; sem responsável e sem momento.
- Nenhum conflito entre características e nenhuma característica deixada para depois.
